# Public Release Gate

A release is blocked if any of the following remains unresolved:

- reputation-sensitive factual claim without adequate evidence;
- claim about knowledge, motive or intent of a living person without primary-level support and dedicated legal review;
- current role/body/proceeding not freshly verified;
- missing source or broken case-to-source mapping;
- real case containing Cipolla classification or a person profile;
- missing counter-reading or explicit limits-of-inference section;
- private/research material in the public tree;
- critical accessibility defect;
- missing legal notice/privacy/correction contact;
- validator failure.

The app is designed to publish only source-grounded public material. Evidence-hold and non-public research claims remain outside this repository.
