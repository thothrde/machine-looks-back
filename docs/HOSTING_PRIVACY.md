# Hosting and privacy profile

Planned public host: GitHub Pages.

The application uses a static, cookie-free and tracker-free frontend with locally bundled runtime resources. Self-experiment state is processed in browser memory during the active session.

GitHub documents that visits to GitHub Pages cause the visitor IP address to be logged and stored for security purposes. The public privacy notice states this hosting-layer processing explicitly.

Official references checked 2026-09-13:
- https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
- https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement
